# Really Blue
- hex: #0000FF, rgb: 0, 0, 255
- Meaning: adding to the hint. The main mechanic is adding letters.
- Like: adding to a list. The hint stays, and more is added to it.

## High
- Rule: the answer contains a word that sounds like the hint. The
  spelling of the hint is not necessarily kept.

## Middle
- Rule: add letters to the hint. The existing letters keep their
  spelling.

## Low
- Rule: build the hint up from a part to a whole, by meaning.
