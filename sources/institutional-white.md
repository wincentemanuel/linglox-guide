# Institutional White
- hex: #F8F8F8, rgb: 248, 248, 248
- Meaning: keeping something about the word the same.
- Like: a request for a duplicate. The answer has to match the hint in one specific way.

## High
- Rule: type a word that sounds the same out loud, even if spelled differently (homophone).
- Example: sea -> see

## Middle
- Rule: type the exact same word back, letter for letter.
- Example: echo -> echo

## Low
- Rule: type a different word with a similar meaning (synonym).
- Example: start -> begin
